# Space Invaders Game

A classic Space Invaders game built with HTML5 Canvas, CSS, and vanilla JavaScript. Features smooth animations, responsive controls, and a modern UI design.

## 🎮 How to Play

- **Move**: Use Arrow Keys (← →) or A/D keys
- **Shoot**: Press Spacebar
- **Goal**: Defend Earth by destroying all alien invaders!

## 🚀 Features

- Player ship with smooth movement controls
- Enemy grid formation (5 rows × 10 columns)
- Collision detection system
- Score tracking and lives system
- Wave progression (new waves after clearing enemies)
- Modern UI with smooth animations
- Responsive design

## 🛠️ Technologies

- HTML5 Canvas for rendering
- Vanilla JavaScript for game logic
- Modern CSS with animations

## 📦 Local Development

1. Clone the repository
2. Open `index.html` in a web browser, or
3. Run a local server:
   ```bash
   node server.js
   ```
   Then visit `http://localhost:8000`
